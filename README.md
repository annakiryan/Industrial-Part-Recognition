# Распознавание промышленных деталей

Система распознавания деталей по изображениям на основе геометрических признаков и сопоставления с эталонными шаблонами.

## Описание

Для каждого изображения детали строится вектор геометрических признаков. Для заранее заданных шаблонов аналогичным образом формируются эталонные векторы.

При распознавании вычисляется расстояние между вектором входного изображения и эталонными векторами. В качестве результата выбирается ближайший шаблон.

```text
Изображение
     ↓
Предобработка и бинаризация
     ↓
Извлечение признаков
     ↓
Вектор признаков
     ↓
Сравнение с эталонными векторами
     ↓
Ближайший шаблон
     ↓
Распознанная деталь
```

## Формирование шаблонов

Новый шаблон проходит следующий pipeline:

```text
DWG
 ↓
DXF
 ↓
Бинарная маска
 ↓
Геометрические признаки
 ↓
Эталонный вектор
 ↓
Набор шаблонов
```

## Признаки

Вектор признаков описывает геометрию детали и включает, в частности:

* размеры и площадь;
* характеристики контура;
* моменты Ху;
* сигнатуру контура;
* дескрипторы Фурье;
* характеристики отверстий.

## Результаты

На проверочной выборке из 63 изображений 11 классов деталей:

* **Top-1 accuracy — 100%**
* **Top-3 accuracy — 100%**

Среди исследованных метрик расстояния наилучший результат показала манхэттенская метрика.
